# TypeScript Assignment 1

This repository contains my solutions for the first TypeScript assignment of the program. It has 8 coding problems solved in `solutions.ts` and 2 technical blog posts.

## Coding Problems

All solutions are in [`solutions.ts`](./solutions.ts). Here's a overview of my solutions:

1. Used optional parameters to solve multiplier not given issue.(`multiplyValue`)
2. Used union of types to handle different inputs and narrow down types for output. (`processInput`)
3. Used readonly tuple types and destructuring. (`formatCoordinate`)
4. Used array generics and avoided .flat() for logical depth. (`concatenateArrays`)
5. Used interface for arguments and filter method. (`Course`, `getPopularCourses`)
6. Used Generics and extended it's keys for type (`pluckValues`)
7. Used Classes, inheritance, and access modifiers (`Employee`, `Manager`)
8. Used async function, Promise with generics and resolve, reject structure with setTimeout (`validateAgeAsync`)
